# Windows Teste - Máquina Alvo Corporativa

## CyberSecurityLabPro

---

# 1. Objetivo

A máquina Windows Teste representa um computador de usuário dentro de uma rede corporativa simulada.

Ela será utilizada para estudos práticos de:

- Blue Team
- Monitoramento
- Análise de logs
- Investigação de incidentes
- Resposta a eventos de segurança

---

# 2. Sistema Operacional

Sistema:

Windows

Função:

Estação de trabalho corporativa simulada.

Uso:

Ambiente controlado para testes de segurança autorizados.

---

# 3. Recursos Planejados

Processador:

- 2 a 4 núcleos

Memória:

- 4 GB a 8 GB RAM

Armazenamento:

- 60 GB ou superior

Rede:

- Conectada à rede isolada do laboratório

---

# 4. Configurações de Segurança

Recursos utilizados:

- Windows Defender
- Firewall do Windows
- Logs de eventos
- Auditoria de usuários

Monitoramento:

- Eventos de login
- Alterações de arquivos
- Processos executados
- Alertas de segurança

---

# 5. Uso no Laboratório

A máquina será utilizada para simular:

- Computador de funcionário
- Ambiente vulnerável controlado
- Geração de eventos para análise SOC
- Investigação de atividades suspeitas

---

# 6. Logs Importantes

Eventos monitorados:

- Logon e Logoff
- Criação de usuários
- Alteração de privilégios
- Execução de programas
- Falhas de autenticação

---

# 7. Integração com SOC

A máquina poderá enviar informações para:

- Sistema SIEM
- Central de monitoramento
- Ferramentas de análise de logs

Objetivo:

Criar alertas e praticar investigação de incidentes.

---

# 8. Segurança do Ambiente

Regras:

- Uso somente no laboratório autorizado
- Criar snapshot antes dos testes
- Manter registros das alterações
- Não utilizar dados reais

---

# 9. Status

Estado atual:

Planejamento.

Próxima etapa:

Instalação da máquina virtual e configuração dos logs.
