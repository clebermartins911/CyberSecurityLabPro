# Linux Server - Servidor do Laboratório

## CyberSecurityLabPro

---

# 1. Objetivo

O Linux Server será utilizado como servidor de infraestrutura dentro do laboratório de cibersegurança.

Sua função é simular serviços existentes em ambientes corporativos.

---

# 2. Funções no Ambiente

Serviços previstos:

- Servidor Linux
- Armazenamento de logs
- Serviços de rede
- Testes de configuração
- Integração com monitoramento

---

# 3. Sistema Operacional

Sistema:

Linux Server

Distribuições possíveis:

- Ubuntu Server
- Debian
- Rocky Linux

Uso:

Ambiente controlado de estudos.

---

# 4. Recursos Planejados

CPU:

- 2 a 4 núcleos

Memória:

- 4 GB RAM ou superior

Armazenamento:

- 40 GB ou superior

Rede:

- Rede isolada do laboratório

---

# 5. Segurança

Configurações previstas:

- Usuários separados
- Controle de permissões
- Firewall ativo
- Atualizações de segurança
- Registro de atividades

---

# 6. Logs

Informações monitoradas:

- Login de usuários
- Serviços executados
- Alterações no sistema
- Tentativas de acesso

---

# 7. Integração SOC

O servidor poderá enviar:

- Logs para SIEM
- Eventos de segurança
- Alertas de monitoramento

Objetivo:

Praticar análise e resposta a incidentes.

---

# 8. Backup e Recuperação

Procedimentos:

- Criar snapshots
- Realizar backups
- Registrar alterações

---

# 9. Status

Estado atual:

Planejamento.

Próxima etapa:

Instalação e configuração do servidor virtual.
