# Inventário de Ferramentas

## CyberSecurityLabPro

---

# 1. Objetivo

Este documento registra as ferramentas utilizadas no laboratório de cibersegurança.

As ferramentas serão usadas para aprendizado, análise, monitoramento e testes autorizados.

---

# 2. Ferramentas Red Team

## Kali Linux

Função:

Ambiente principal para testes de segurança.

Uso:

- Reconhecimento.
- Análise de vulnerabilidades.
- Testes autorizados.

---

## Nmap

Função:

Análise de rede.

Uso:

- Descoberta de hosts.
- Análise de portas.
- Identificação de serviços.

---

## Wireshark

Função:

Análise de tráfego de rede.

Uso:

- Captura de pacotes.
- Investigação de comunicação.
- Análise de protocolos.

---

## Burp Suite

Função:

Análise de aplicações web.

Uso:

- Testes em aplicações próprias.
- Identificação de problemas de segurança.

---

# 3. Ferramentas Blue Team / SOC

## Wazuh

Função:

Monitoramento de segurança.

Uso:

- Coleta de logs.
- Alertas.
- Detecção de eventos.

---

## ELK Stack

Função:

Análise e visualização de dados.

Componentes:

- Elasticsearch.
- Logstash.
- Kibana.

Uso:

- Pesquisa de logs.
- Dashboards.
- Investigação.

---

# 4. Ferramentas Forenses

Uso:

Análise de evidências digitais.

Categorias:

- Análise de arquivos.
- Logs.
- Memória.
- Sistemas.
