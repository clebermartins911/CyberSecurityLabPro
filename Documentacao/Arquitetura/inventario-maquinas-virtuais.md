# Inventário de Máquinas Virtuais

## CyberSecurityLabPro

## Objetivo

Registrar as máquinas virtuais utilizadas no laboratório de cibersegurança.

O ambiente será utilizado para estudos de:

- Red Team
- Blue Team
- SOC
- Forense Digital
- Resposta a Incidentes

---

# Máquinas Planejadas

## 1. Kali Linux

Função:

- Máquina de testes autorizados
- Análise de segurança
- Ferramentas Red Team

Sistema:

- Kali Linux

Uso:

- Reconhecimento
- Análise de vulnerabilidades
- Testes controlados

---

## 2. Windows Cliente

Função:

- Máquina alvo de testes
- Simulação de ambiente corporativo

Sistema:

- Windows

Uso:

- Coleta de logs
- Investigação
- Análise de eventos

---

## 3. Linux Server

Função:

- Servidor de laboratório

Sistema:

- Linux Server

Uso:

- Serviços
- Logs
- Monitoramento

---

## 4. SIEM / SOC

Função:

- Central de monitoramento

Uso:

- Receber logs
- Criar alertas
- Investigar incidentes

---

# Regras do Ambiente

- Rede isolada
- Testes somente autorizados
- Snapshots antes de alterações
- Registro das atividades
