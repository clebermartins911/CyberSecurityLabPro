# Inventário de Máquinas Virtuais

## CyberSecurityLabPro

---

# 1. Objetivo

Este documento descreve as máquinas virtuais utilizadas no laboratório CyberSecurityLabPro.

O ambiente será utilizado para estudos práticos de:

- Red Team.
- Blue Team.
- SOC.
- Forense Digital.
- Resposta a Incidentes.

---

# 2. Arquitetura das Máquinas

## Máquina 01 - Kali Linux

Função:

Red Team / Testes de Segurança

Responsabilidades:

- Reconhecimento.
- Análise de vulnerabilidades.
- Testes autorizados.
- Ferramentas de segurança.

Sistema:

Kali Linux

---

## Máquina 02 - Windows Cliente

Função:

Estação de usuário.

Responsabilidades:

- Simulação de ambiente corporativo.
- Análise de eventos.
- Testes de segurança.

Sistema:

Windows 10/11

---

## Máquina 03 - Ubuntu Server

Função:

Servidor Linux.

Responsabilidades:

- Serviços de rede.
- Aplicações de teste.
- Coleta de logs.

Sistema:

Ubuntu Server

---

## Máquina 04 - Windows Server

Função:

Ambiente corporativo.

Responsabilidades:

- Active Directory.
- Usuários e grupos.
- Políticas de segurança.

Sistema:

Windows Server

---

## Máquina 05 - SIEM/SOC

Função:

Monitoramento de segurança.

Responsabilidades:

- Receber logs.
- Criar alertas.
- Investigar eventos.

Ferramentas planejadas:

- Wazuh.
- ELK Stack.
- Outras ferramentas de monitoramento.

---

# 3. Rede do Laboratório

Todas as máquinas devem permanecer em ambiente controlado.

Tipos de rede:

- Rede interna.
- Host-only.
- NAT controlado.

Objetivo:

Evitar impacto em equipamentos externos.

---

# 4. Controle das Máquinas

Cada máquina deve possuir:

- Nome identificado.
- Sistema atualizado.
- Snapshot de segurança.
- Documentação.
- Registro de alterações.

---

Futuras adições:

- Ambiente de simulação empresarial.
